# Awesome Runway Gen 4

*Unofficial community list for Runway Gen-4. Not affiliated with Runway. All trademarks belong to their owners.*

A short, verified list of links for people working with runway gen 4, Runway's image-to-video model. Every entry comes from the Runway help center article on Gen-4, the research post that introduced it, or the Morphic page that hosts Gen-4 Image. No guessed documentation URLs; where a resource is only named, it is listed without a link.

> Starting from text rather than an image? [Try Kyncept - Veo 3.1 text-to-video and image-to-video in the browser](https://kyncept.com?utm_source=github&utm_medium=ugc&utm_campaign=awesome-runway-gen-4&utm_content=readme-top&utm_term=tier-r), which also generates the stills.

## Official resources

- [Introducing Runway Gen-4](https://runway.com/research/introducing-runway-gen-4) - Runway's research post announcing the model.
- [Creating with Gen-4 Video](https://help.runwayml.com/hc/en-us/articles/37327109429011-Creating-with-Gen-4-Video) - The help center article: credits, durations, resolutions, prompt limit and step-by-step settings.
- [Gen-4 help section](https://help.runwayml.com/hc/en-us/sections/39888423025683-Gen-4) - All Gen-4 articles in one place.
- [Runway Models](https://help.runwayml.com/hc/en-us/sections/47297541368595-Runway-Models) - Parent section listing every Runway model guide.
- [Model Guides](https://help.runwayml.com/hc/en-us/sections/50990795422739-Model-Guides) - One level up: guides for all models available in the app.
- [Creating with Runway](https://help.runwayml.com/hc/en-us/categories/1500001930562-Creating-with-Runway) - The help category for hands-on creation.
- [Runway help center](https://help.runwayml.com/hc/en-us) - Home page for support articles.
- [Runway app login](https://app.runwayml.com/login) - Where you actually generate.

## Getting started

- [Tool mode, Video tab](https://app.runwayml.com/video-tools/teams/placeholder/ai-tools/generate?mode=tools&tool=video) - The panel where Gen-4 and Gen-4 Turbo are selected from the model dropdown.
- [Animate Frames app](https://app.runwayml.com/video-tools/teams/placeholder/ai-tools/generate?tool=apps&app=keyframes) - Runway's pointer for keyframe workflows.
- [Creating with Apps](https://help.runwayml.com/hc/en-us/articles/45570040112531-Creating-with-Apps) - Full list of task-specific apps in the workspace.
- [How to submit a support request](https://help.runwayml.com/hc/en-us/articles/20821762056723-How-to-submit-a-support-request) - When a generation fails or credits look wrong.

## Tutorials and articles

- [Creating with Gen-4.5](https://help.runwayml.com/hc/en-us/articles/46974685288467-Creating-with-Gen-4-5) - The newer model Runway now recommends for text-to-video and image-to-video.
- [Edit Studio Aleph 2.0](https://help.runwayml.com/hc/en-us/articles/51683104370451) - Runway's current video-to-video route, since Gen-4 is image-to-video only.
- [Runway Gen-4 Image on Morphic](https://morphic.com/resources/models/runway-gen4-image) - Third-party model page with use cases and two short prompt examples.
- [Seedance 2.5 on Morphic](https://morphic.com/resources/models/seedance-2-5) - Listed alongside Gen-4 Image; useful for comparing clip length and reference-input limits.

## Tools and integrations

- [Morphic Studio](https://studio.morphic.com/signin?utm_campaign=resources&utm_content=nav_start_creating) - Where Gen-4 Image runs outside Runway, with 1080p and up to 10-second output.
- [Morphic workflows](https://morphic.com/workflows) - Ready-made creative pipelines that can include Gen-4 Image.
- [Morphic use cases](https://morphic.com/usecases) - Product animation, portrait animation and marketing examples.
- [Morphic showcase](https://morphic.com/showcase) - Finished work for reference.

## Alternatives

- [Kyncept](https://kyncept.com?utm_source=github&utm_medium=ugc&utm_campaign=awesome-runway-gen-4&utm_content=readme-top&utm_term=tier-r) - Veo 3.1 text-to-video and image-to-video plus image generation, in the browser; no input image required to start.
- [Gen-4.5](https://help.runwayml.com/hc/en-us/articles/46974685288467-Creating-with-Gen-4-5) - Runway's own successor for both text and image input.
- Gen-4 Turbo - Same inputs and resolutions as Gen-4 at 5 credits per second instead of 12; documented in the Gen-4 article above.
